# GitHub Profile Analyzer

## Overview

Analyze any public GitHub profile using live GitHub API data.

---

## Features

- Fetch user profile information
- Analyze repository languages
- Dynamic GitHub statistics
- Real-time API data

---

## Files

- `fetch_profile.py`
- `analyze_repos.py`

---

## Installation

```bash
pip install requests
```

---

## Usage

```bash
python fetch_profile.py
python analyze_repos.py
```

---

## Example

```text
GitHub Username: torvalds

Followers: 250000+
Public Repos: 8
Languages:
C: 5
Python: 2
```
